# Torneo_Futbol
# Torneo de fútbol aficionado

Sistema para gestionar un torneo de fútbol aficionado: equipos, jugadores,
calendario, resultados y tabla de posiciones.
Proyecto de Desarrollo de Software III · Universidad del Valle · Equipo Visca Barça.

## Estructura del repositorio
| Carpeta | Contenido |
|---|---|
| `torneo-service/` | Servicio Spring Boot: equipos, jugadores, calendario y resultados |
| `estadisticas-service/` | Servicio Spring Boot: tabla de posiciones y goleadores |
| `frontend/` | Cliente Angular |
| `infra/` | `compose.yaml` y configuración de Keycloak |
| `docs/` | Bitácora de decisiones y mediciones |
